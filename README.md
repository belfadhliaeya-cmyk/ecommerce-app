# 🛒 Ecommerce App

## 📌 Description
Simple ecommerce website built with PHP & MySQL.

## 🚀 Features
- User registration & login
- Product listing
- Shopping cart
- Order management

## 🧰 Technologies
- PHP
- MySQL
- HTML / CSS
- JavaScript

## ⚙️ Installation
1. Clone repository
2. Import database.sql in phpMyAdmin
3. Start XAMPP (Apache + MySQL)
4. Open: http://localhost/ecommerce app
