# 🛒 Ecommerce App

## 📌 Description
Projet e-commerce يسمح للمستخدم:
- تصفّح المنتجات
- إضافة للسلة
- عمل طلب (commande)
- تسجيل الدخول/إنشاء حساب

## 🧰 Technologies
- PHP
- MySQL
- JavaScript
- HTML/CSS
- XAMPP

## ▶️ Installation

1. Clone repo:
git clone https://github.com/belfadhliaeya-cmyk/ecommerce-app.git

2. حط المشروع في:
C:\xampp\htdocs\

3. شغّل XAMPP (Apache + MySQL)

4. Import database:
- افتح phpMyAdmin
- اعمل import لملف database.sql

5. افتح في navigateur:
http://localhost/ecommerce app
